# 💻 My Personal Portfolio Website

Welcome to the core repository of my personal portfolio. This project serves as a centralized hub showcasing my engineering skills, responsive design practices, and frontend/backend integration across several real-world applications.

🌐 **Live Deployment:** [View My Live Portfolio](https://zulfiqarteams.github.io/Portfolio_Website/)

---

## 🛠️ Tech Stack Used

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Responsive Web Design (Media Queries)
- **Deployment & CI/CD:** GitHub Pages / GitHub Actions

---

## 📂 Featured Sub-Projects & Modules

This portfolio isn't a single static page — it's a container for several specialized web applications, each built to solve a distinct problem:

### 🌟 1. Zulfiqar Restaurant
- **Description:** A clean, modern, fully interactive restaurant landing page.
- **Key Features:** Responsive navigation, dynamic menu displays, and sleek UI components designed to maximize engagement.

### ☀️ 2. Weather Application
- **Description:** A real-time weather tracking app that queries external API data.
- **Key Features:** Dynamic city search, asynchronous data fetching (`fetch` / `async-await`), and conditional UI rendering based on current conditions.

### 📝 3. Advanced To-Do List App
- **Description:** A productivity app built for robust task management.
- **Key Features:** Persistent data storage, live state updates, filtering options, and an intuitive interface.

### 🌲 4. Tree Builder & Sub-Modules
- **Description:** Specialized logical and structural mini-apps (including *Tree Builder* and *Riwaayah*) demonstrating algorithmic thinking, clean DOM manipulation, and structured JavaScript logic.
